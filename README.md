## ✨ Sobre Este Proyecto

Este proyecto representa mucho más que una simple página web. Es el testimonio de un **viaje de transformación** — no solo físico (como el Jiu-Jitsu que representa), sino también profesional.

### 🎓 Mi Historia como Desarrollador Autodidacta

Antes de escribir una sola línea de código, jamás hubiera imaginado que terminaría sentado frente a una pantalla creando algo desde cero. Este proyecto fue **mi primer contacto real con el desarrollo web**:

- 📚 Aprendí HTML, CSS y JavaScript mediante autoaprendizaje
- 🔍 Investigué, probé, fallé y volví a intentar
- 💡 Cada decisión de diseño fue un aprendizaje
- 🌱 Mi primer proyecto creado con mis propias manos

El resultado no era perfecto, y precisamente ahí estaba la belleza del proceso.
